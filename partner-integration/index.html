Fill in the user details below and click the button. Your server will call the AskVERA API and redirect you to the chat app.

Your system's unique user identifier (optional but recommended)
Pet (optional)
How it works: When you click the button, the demo server (1) authenticates with AskVERA via OAuth, (2) calls POST /api/askvera/v1/partner/login-token with the user/pet data, (3) receives a loginUrl, and (4) redirects your browser to that URL. The user lands directly in the chat — no sign-up or payment required.
